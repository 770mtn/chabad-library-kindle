# ספריית חב״ד לקינדל — אתר להורדת קובצי PDF

## מה זה עושה
- אתר עברי, מותאם לנייד ולמחשב.
- סורק דפים ציבוריים באתר chabadlibrary.org ובקטלוג כדי למצוא קישורי PDF ישירים.
- מאפשר חיפוש וסימון קבצים.
- מוריד קבצים שנבחרו לחבילת ZIP אחת, שאפשר לחלץ ולהעתיק לתיקיית Documents בקינדל.

## הרצה מקומית
נדרש Python 3.10 ומעלה.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
פתחו http://127.0.0.1:5000

## פריסה לאינטרנט
הפרויקט כולל `render.yaml` ו-`Procfile` לפריסה בשירות אירוח תומך Python, כגון Render. יש ליצור שירות חדש ולחבר את תיקיית הפרויקט או מאגר GitHub. קובץ ZIP שנוצר נשמר זמנית על השרת; בשירותי אירוח חינמיים הוא עלול להימחק בהפעלה מחדש, ולכן יש להוריד אותו מיד כשהוא מוכן. האתר אינו מתארח עדיין — צריך לפרוס אותו בחשבון אירוח כדי לקבל כתובת אינטרנט ציבורית.

## מגבלות חשובות
- אב-טיפוס: סריקה לפי קישורים, לא קטלוג מלא ומובטח של כל הספרים.
- סורק רק דפים וקובצי PDF ציבוריים; לא עוקף כניסה, חסימות, או מגבלות גישה.
- הסריקה מוגבלת למספר דפים לבחירת המשתמש, והאתר עשוי לשנות מבנה.
- יש להוריד ולהשתמש רק בקבצים שהורדתם מותרת בהתאם לזכויות ולתנאי האתר.
- קובצי PDF סרוקים אינם מומרים אוטומטית ל-EPUB; הם נשארים PDF המתאים לפתיחה ב-KOReader.
- חבילה מוגבלת ל-500 קבצים בכל פעם. מומלץ לבחור סדרה אחת או כמה כרכים בכל חבילה.
